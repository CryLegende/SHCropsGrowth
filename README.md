## Présentation

Modifie la vitesse de croissance des cultures individuellement et corrige le bug du cactus.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shcropsgrowthreload` | — | Recharge la configuration du plugin SHCropsGrowth. | `shcropsgrowth.reload` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shcropsgrowth.reload` | Permet à l'utilisateur de recharger la configuration de SHCropsGrowth. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/SHCropsGrowth/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
